# Scripture interpretation and sourcing protocol

1. Extract all fields *as written*; keep date, references, language, and roles. Underline any ambiguities rather than smoothing them away. An attached sermon file's `Pemahaman Teks`, `Korelasi`, and `Pokok-Pokok Pengembangan Khotbah` are primary evidence for the brief.
2. Synthesize: (a) divine action/character, (b) human response, (c) moral/spiritual tension, (d) stated congregational goal, (e) common thread across readings, (f) what illustration must avoid implying.
3. Distinguish **text explicitly describes**, **sermon file explains**, **designer infers**, and **invented visual metaphor**. A visual inference must never be presented as Biblical fact.
4. Read full scripture text in a verified translation only when accessible and permitted; if only references and supplied exegesis are available, state scope plainly. Observe translation/copyright boundaries. Do not fabricate verse quotes.
5. Beware: poetic metaphor ≠ literal historical scene; parable ≠ documentary report; not all books share the same genre. Avoid collapsing warnings, judgment, grace, and response into simplistic "everything is happy" scenes.
6. Use the theme **objectives** to check that the proposed visual serves what congregation should understand or do. A beautiful object that references the title but not the aim is insufficient.
7. For live church use, respect Gereja Toraja doctrinal/context material supplied. If theological interpretations conflict or critical details absent, flag for human review; do not claim ecclesial authority.
8. When contemporary Toraja adaptations are used, explicitly label "aplikasi masa kini" rather than reconstruction of Bible events.
9. Untuk setiap konsep visual dan paket produksi akhir, susun **Keterangan Gambar baku** siap pakai untuk warta jemaat dan media ibadah gereja. Format wajib:
   - Header baris 1: `Gambar Tema tanpa teks pendukung. [Tanggal]`
   - Header baris 2: `Ilustrasi: [Nama Ilustrasi] — [Referensi Alkitab]`
   - Isi: 1–2 kalimat menggambarkan adegan visual secara hidup dan hangat, disambung 2–3 kalimat refleksi teologis ("Gambaran ini mengingatkan bahwa... Panggilan ini menggerakkan umat untuk...")
   - Penutup: `Tema: “[Judul Tema]”`
